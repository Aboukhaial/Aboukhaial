# مجلد الموسيقى

ضع ملف الموسيقى هنا باسم:

wedding-song.mp3

المسار الكامل يجب أن يكون:

/public/music/wedding-song.mp3

ملاحظات:
- الصيغة المفضلة MP3
- الحجم المفضل أقل من 5MB
- الموسيقى لن تبدأ تلقائيا احتراما لسياسات المتصفح، بل عند ضغط زر الموسيقى
- إذا لم يوجد الملف، سيختفي زر الموسيقى تلقائيا بدون أي خطأ

يمكنك استخدام أي موسيقى رومانسية هادئة بدون حقوق أو بترخيص.
